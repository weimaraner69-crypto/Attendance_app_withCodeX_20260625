# Document Inventory

初回棚卸しと定期見直しで、ドキュメントの正本・更新責務・保管方針を記録します。

| Document | Classification | Source of truth | Review trigger |
| --- | --- | --- | --- |
| `NEXT.md` | task queue | Yes | plan changes |
| `SECURITY.md` | security policy | Yes | security policy changes |
| `docs/architecture.md` | architecture | Yes | responsibility boundary changes |

不要になった文書は、初回棚卸しでは削除せず、候補と判断理由を記録します。
